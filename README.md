# MacOS PortFolio

It is an interactive , macos styled developer portfolio website that simulates a modern desktop os directly in browser.

## Description

This project is a personal portfolio website designed to look like an Apple macos desktop. Instead of scrolling through a normal , boring webpage , visitors can click around on a computer screen , you can open and move app windows , click icons in the botton dock , drag projct folders around the desktop wallpaper , and read articfles in a mock safari browser , It also lets people view a resume , look throught photo galleries, and see my tech stack in the terminal app. It is build using modern web tools like React and Tailwind CSS to make all the animations feel smooth and fun to explore.

## Installing steps

* Download or clone this project form Github to your computer :
```git clone https://github.com/pari0192/macfolio.git```

* move into your project folder
```cd macfolio```

* install all required packages
```npm i```

* start the local server
```npm run dev```
